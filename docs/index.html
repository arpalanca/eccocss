Ecco CSS

Include Ecco. Write HTML. Done.

What is this?

Ecco is a single stylesheet that styles semantic HTML for you. Link it once. No classes required for a clean, readable page.

  • Classless by default
  • Light & dark via prefers-color-scheme
  • Themeable with CSS variables
  • No JavaScript

Quick start

Download the file

Prefer to host the CSS yourself? Grab a file and drop it into your project:

  • ecco.min.css (minified, recommended)
  • ecco.css (readable source)
  • Download ZIP (full repository)

Then link it locally:

<link rel="stylesheet" href="css/ecco.min.css" />

You can also copy dist/ecco.min.css from a local clone of this repo.

Use the CDN

No download needed. Link Ecco from jsDelivr:

<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/arpalanca/eccocss@main/dist/ecco.min.css"
/>

For production, pin a tag or commit (replace @main with @v0.1.0 or a SHA).

Install with npm

npm install github:arpalanca/eccocss
<link rel="stylesheet" href="node_modules/eccocss/dist/ecco.min.css" />

Starter HTML

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <meta name="color-scheme" content="light dark" />
    <title>Hello Ecco</title>
    <link rel="stylesheet" href="css/ecco.min.css" />
  </head>
  <body>
    <main>
      <h1>Hello</h1>
      <p>Semantic HTML, styled automatically.</p>
      <button>Get started</button>
    </main>
  </body>
</html>

Misc

How do I theme Ecco?

Override variables on :root. For example, --ecco-primary, --ecco-bg, and --ecco-width. See the README customization section.

64%

Light and dark follow prefers-color-scheme automatically. Switch your OS theme to preview.
