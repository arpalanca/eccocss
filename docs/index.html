Ecco CSS

Include Ecco. Write HTML. Done.

Overview

Ecco is one stylesheet that styles semantic HTML for you. No class names required for a clean, readable page.

  • Classless by default
  • Light and dark via prefers-color-scheme
  • Themeable with CSS variables
  • No JavaScript required for the framework

How to read these docs. Live demos show the result. Open the HTML tab (or a code panel) to copy the markup. Use Copy on any sample.

Install

Pick one path. CDN is fastest. Download or npm if you want the file in your project.

Drop this into your <head>:

<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/arpalanca/eccocss@main/dist/ecco.min.css"
/>

For production, pin a tag or commit SHA instead of @main.

Grab a file and host it yourself:

  • ecco.min.css (minified)
  • ecco.css (readable)
  • Download ZIP 
<link rel="stylesheet" href="css/ecco.min.css" />
npm install github:arpalanca/eccocss
<link rel="stylesheet" href="node_modules/eccocss/dist/ecco.min.css" />

Usage

Write semantic HTML. Put page content in header, main, footer, or similar landmarks as direct children of body. 

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <meta name="color-scheme" content="light dark" />
    <title>Hello Ecco</title>
    <link rel="stylesheet" href="css/ecco.min.css" />
  </head>
  <body>
    <main>
      <h1>Hello</h1>
      <p>Semantic HTML, styled automatically.</p>
      <button>Get started</button>
    </main>
  </body>
</html>

Forms

Labels, inputs, selects, textareas, checkboxes, and radios are styled automatically. Keep forms short; stack fields vertically.

Contact 
<form>
  <fieldset>
    <legend>Contact</legend>
    <label for="name">Name</label>
    <input id="name" name="name" type="text" />
    <label for="email">Email</label>
    <input id="email" name="email" type="email" />
    <label for="about">Message</label>
    <textarea id="about" name="about"></textarea>
    <button type="submit">Send</button>
  </fieldset>
</form>

Theming

Override CSS variables on :root. Light and dark follow the system preference automatically. 

:root {
  --ecco-hue: 160;
  --ecco-primary: hsl(160 55% 35%);
  --ecco-width: 52rem;
  --ecco-font-family: "IBM Plex Sans", system-ui, sans-serif;
}

Common tokens: --ecco-bg, --ecco-text, --ecco-primary, --ecco-border, --ecco-width. Full list in css/ecco.css.
